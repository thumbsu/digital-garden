# Claude Code가 한 달치 대화를 분석해주는 기능이 있다

Claude Code를 쓰다 보면 문득 이런 생각이 든다. 나는 AI랑 잘 협업하고 있는 걸까? 답답한 상황이 반복되는 것 같은데 뭐가 문제인지 모르겠다.

그런데 Claude Code에 `/insights`라는 명령어가 있다. 지난 한 달 동안 AI와 나눈 대화를 전부 긁어모아서 분석 리포트를 만들어주는 기능이다. 처음 알았을 때는 "이런 게 있었어?" 싶었다.

## 어떻게 작동하는가

과정은 대략 이렇다.

먼저 로컬 컴퓨터에 쌓인 대화 기록을 수집한다. 단, 너무 짧은 대화는 제외한다. 그다음 각 대화에서 기본 정보를 뽑는다. 얼마나 길었는지, 어떤 종류의 작업이었는지, 얼마나 자주 사용했는지 같은 것들.

그 뒤에 긴 대화들은 따로 요약하고, 각 대화마다 만족도를 평가한다. "이 대화, 잘 풀렸나 아니면 답답했나?" 같은 판단을 AI가 내린다. 이걸 한 달치 통으로 모아서 패턴을 분석하고, 마지막에 브라우저에서 바로 열리는 HTML 리포트를 생성한다.

클릭 한 번이면 깔끔한 보고서가 뜬다.

## 보고서 안에 뭐가 있나

보고서는 크게 네 부분으로 나뉜다.

**요약 섹션**이 맨 먼저 나온다. 잘 되는 작업이 뭔지, 어디서 막히는지, 어떻게 개선하면 좋을지 텍스트로 정리해준다. AI가 나 대신 내 사용 패턴을 읽고 "당신은 이런 식으로 쓰고 있고, 이 부분이 자주 막힌다"고 말해주는 셈이다.

**통계 대시보드**에는 숫자들이 들어간다. 총 메시지 수, 얼마나 많은 코드 줄을 수정했는지, 파일은 몇 개나 건드렸는지 같은 지표다.

**마찰 분석**이 흥미롭다. 어떤 상황에서 대화가 잘 안 풀렸는지를 정리해준다. 한 사례에서는 1순위 마찰 원인이 "성급한 행동"으로 46건이었다. AI가 사용자 말을 다 듣기도 전에 혼자 실행해버리는 패턴이다. 이걸 숫자로 보니까 실감이 난다.

**만족도 평가**는 각 세션을 짜증남, 약간 답답함, 보통, 만족, 행복함 다섯 단계로 분류해서 보여준다. 내가 어떤 날 AI와 잘 맞았고 어떤 날 삐걱거렸는지 한눈에 볼 수 있다.

마지막으로 **맞춤 설정 규칙**이 자동으로 생성된다. Claude Code는 `CLAUDE.md`라는 파일에 지시사항을 적어두면 AI가 그걸 읽고 행동 방식을 조정하는데, 분석 결과를 바탕으로 이 파일에 바로 붙여넣을 수 있는 규칙을 제안해준다. 실용적으로는 이 부분이 가장 쓸 만하다.

## 그렇다고 맹신하면 안 된다

기능 자체는 신선하지만 문제가 꽤 있다.

가장 큰 문제는 할루시네이션이다. 비용을 줄이려고 분석에 작은 모델을 사용하는데, 이 모델이 숫자를 지어낼 때가 있다. 실제로는 10번 사용한 기능을 300번이라고 보고하는 식이다. 통계 숫자를 곧이곧대로 믿으면 안 된다.

버그도 여러 건 있고, 최근 대화에 분석이 치우치는 편향도 있다. 즉, 구체적인 수치보다는 전반적인 패턴과 경향성을 읽는 용도로 써야 한다. "내가 이런 상황에서 자주 막히는구나"라는 방향성을 잡는 데는 충분히 유용하다.

## 왜 쓸 만한가

다른 AI 코딩 도구들에는 이런 자기 성찰 기능이 없다. 그냥 쓰고 끝이다. Claude Code는 사용 기록을 보고 "당신은 이렇게 쓰고 있고, 이렇게 바꾸면 더 잘 쓸 수 있다"고 말해준다. 잘 훈련된 매니저한테 피드백 받는 느낌이라는 표현이 과하지 않다.

특히 CLAUDE.md 규칙 자동 생성은 진입 장벽을 낮춰준다. 어떤 규칙을 적어야 할지 몰라서 파일을 비워두는 사람한테는 시작점이 생기는 것이다.

## 사용 조건

아무나 쓸 수 있는 건 아니다.

- Claude Code Pro Plus 또는 Max 구독이 필요하다
- 최소 2~4주 이상 사용 데이터가 쌓여 있어야 의미 있는 분석이 나온다
- Claude Code 최신 버전이 설치되어 있어야 한다

이 조건이 갖춰졌다면, 터미널에서 `/insights`를 치는 것만으로 시작된다.
